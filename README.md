# Rently

Rently est un système de gestion de location de véhicules développé en C++ dans le cadre d'un projet personnel. Ce projet me permet de mettre en pratique la programmation orientée objet, la conception logicielle, les structures de données ainsi que le développement d'applications.

Le projet est inspiré de mon expérience professionnelle actuelle dans le domaine de la location de véhicules.

Le projet est actuellement en développement.

## Objectifs

L'objectif de Rently est de simuler les principales opérations d'une entreprise de location de véhicules, notamment :

- Gérer une flotte de véhicules
- Gérer les clients
- Créer et gérer les locations
- Suivre la disponibilité des véhicules
- Valider les informations des clients et de leur permis de conduire
- Conserver l'historique des locations
